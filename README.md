# HyperToon Playground

Unity project for experimenting with ShaderLab and other rendering tech such as Blit passes, Skyboxes, and custom render features. Originally created for [HyperStars](https://hyperstarsgame.vercel.app/). (Read more about HyperStars [here](https://www.evetshuu.com/games/hyperstars.html))
